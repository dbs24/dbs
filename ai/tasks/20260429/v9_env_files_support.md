# .env files support

## new functionality should be added

1. Every project that has application.yml should have added reading support functionality.env files
2. All values of variables set via $ (${}) from application.yml should be moved to their own separate files .env files
3. General functionality should be added that will allow loading the values specified in the .env files when starting the springboot application.
4. After all the changes, all the tests should be run and checked.
