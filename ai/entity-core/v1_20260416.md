# Refactoring of EntityCore model

following steps should be performed

## EntityCore

| Entity                        | Description                                                                    |
|:------------------------------|:-------------------------------------------------------------------------------|
| data class Entity             | data class Entity should be removed. Table core_entities should be deleted     |
| abstract class EntityCoreVal  | should be deleted     <br/>                                                    |
| data class Action  | playerId should be generated from database sequence (nextval('seq_action_id')) |
| data class Action  | new Attribute shuld be added: EntityTypeEnum ( entity_type_id, тип int )       |
| data class Action  | For the Action entity, you must create a repository that allows you to save the Action entity to the database. The repository must be inherited from the CoroutineCrudRepository entity.    |


## Service

| Entity       | Description                                                                                                                                                                            |
|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| r2dbcService | method executeActionCo, executeAction should be removed                                                                                                                                |
| r2dbcService | An asynchronous service (@EventListener, @Async) should be created that accepts messages, and upon receipt of this message registers an Action on an abstract entity in the database. |


## Player (mgmt project)

| Entity                | Description                                                                                                                                                                                                                                                      |
|:----------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| data class Player     | playerId should be generated from database sequence (nextval('seq_action_id'))                                                                                                                                                                                   |
| data class Player     | new attributes should be added  <br><pre>@Transient <br>val entityType: EntityTypeEnum <br>@Column("status_id") <br>val entityStatus: EntityStatusEnum, <br>val createDate: OperDate, <br>val modifyDate: OperDate, <br>val closeDate: OperDateNull = null</pre> |
| data class PlayerHist | also add new attributes in PlayerHist|
| data class Player     | For existing entries in the cc_players table, the new fields must be taken from the corresponding entries in the core_entities table. core_entities.entity_id = cc_players.player_id                                                                             |
| data class Player     | Need migration spript (Flyway)  for create new attrs                                                                                                                                                                                                             |
| data class Player     | When the Player entity is saved, a message should be sent to the service for registering Actions on the entity (core_actions)                                                                                                                                    |
